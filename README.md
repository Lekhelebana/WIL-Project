 ITC327W
 Nama Nameng — Mobile and Web-Based Ordering, Payment and Queue Management System

A Work-Integrated Learning (WIL) project for ITC327W, developed for Nama Nameng, a local food/braai business currently operating on a fully manual, in-person ordering process. The system aims to reduce queue times, prevent order miscommunication, and give the owner a simple way to manage orders and menu items digitally.

Tech Stack

- Mobile App: Flutter (customer-facing ordering app)
- Web Dashboard: ASP.NET (owner/staff menu and order management)
- Backend: Supabase (database, authentication, real-time synchronisation)
